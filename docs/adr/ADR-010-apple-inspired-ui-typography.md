# ADR-010: Apple Esintili Özgün UI ve Merkezi Tipografi

**Durum:** Build 123–126 ile kabul edildi ve uygulanıyor.

**Karar:** Uygulama Apple’ın okunabilirlik ve etkileşim ilkelerinden esinlenen
özgün arayüz kullanır. Merkezi sistem font zinciri ve semantik tipografi ölçeği
zorunludur.

**Sonuç:** SF font dosyaları uygulamaya gömülmez. Apple sistem fontu işletim
sisteminden seçilir; diğer platformlar güvenli fallback kullanır. Gövde 17 px,
ana başlıklar 34/28/22 px ve temel etkileşim hedefi en az 44 px’tir.
