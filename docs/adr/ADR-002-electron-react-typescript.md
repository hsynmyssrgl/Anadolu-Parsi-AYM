# ADR-002: Windows Öncelikli Electron + React + TypeScript

**Durum:** Kabul edildi ve uygulanıyor.

**Karar:** Windows masaüstü istemcisi Electron, React, Vite ve TypeScript ile
geliştirilir. Alan ve application modeli mümkün olduğunca saf TypeScript kalır.

**Sonuç:** Windows ilk gerçek platformdur. macOS taşınabilirliği ve gelecekte
okuma ağırlıklı iPhone/iPad/Watch/Vision Pro companion istemcileri desteklenir;
mobil bağımsız işlem motoru değildir.
