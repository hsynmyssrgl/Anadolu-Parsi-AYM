# ADR-009: Doğrulama Kanıtı Dürüstlüğü ve Promotion Kontrolü

**Durum:** Kabul edildi.

**Karar:** Yalnız gerçekten çalıştırılan kapı PASS/FAIL olabilir. Çalıştırılmayan
kapı NOT_RUN kalır. Tanı koşusu resmî PASS yerine geçmez.

**Sonuç:** Build sonuçları sonraki build’e taşınmaz. Bronze Final, Code Freeze,
Silver veya Gold otomatik başlamaz; açık ürün sahibi kararı gerekir.
