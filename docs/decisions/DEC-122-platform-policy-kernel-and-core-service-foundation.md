# DEC-122 — Platform Policy Kernel and Core Service Foundation

Date: 2026-08-04
Status: ACCEPTED / FOUNDATION STARTED
Release: Bronze 04.08.2026.27

Every Windows, Apple, worker, cluster and signed-plugin component must obtain a fail-closed decision from one Platform Policy Kernel. A headless Windows Core Service is the authoritative future process boundary; Desktop becomes a client. This release adds the first source packages and ratchet gates but does not claim distributed, OCR, communication or Apple functionality complete.
