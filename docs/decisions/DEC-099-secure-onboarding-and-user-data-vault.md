# DEC-099 — Güvenli ilk kurulum ve kullanıcı veri kasası

**Karar:** Build 209 ile Windows ilk kurulum deneyimi, yerel parola + Apple/Google/Microsoft kimlik sağlayıcı mimarisi ve giriş öncesi kilitli kullanıcı veri kasası Proje Anayasası V4'e bağlanır.

Kalıcı kullanıcı verisi doğrulama öncesi açılamaz; parola + Windows cihaz koruması olmadan kasa anahtarı çözülemez. Haricî kimlik uygulama yetkisi değildir. Arşiv belgeleri yalnız uygulama içinde güvenli önizlenir. Aynı-kullanıcı malware/yönetici ve aktif-oturum sayfa şifreleme sınırı açıkça `OPEN-021`, yan artifact kapanışı `OPEN-022` olarak tutulur.
