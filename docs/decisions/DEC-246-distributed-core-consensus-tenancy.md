# DEC-246 — Dağıtık Core Service consensus ve tenancy temeli

Durum: PLANNED / LOCAL_IMPLEMENTATION_STARTED

34-I mevcut headless Core Service'i cluster sözleşmeleriyle genişletir. Özel consensus algoritması yazılmaz; olgun Raft sağlayıcısı zorunlu porttur. Sağlayıcı yoksa quorum commit ve snapshot bootstrap fail-closed olur. Üretim sağlayıcısı doğrulanmadıkça sentetik sağlayıcı yalnız açık test bayrağıyla çalışabilir. Lider term/fencing token, quorum kaybı, policy version, revocation epoch, key epoch, clusterId/familyId tenancy ve entityVersion her yazıda doğrulanır. Idempotency anahtarları cluster/family kapsamında benzersizdir; provider commit index kalıcı head'den ileri değilse veya provider boolean/evidence şekli exact değilse runtime safe mode'a girer. Provider serbest hata metni istemci kararına taşınmaz.

SQLite projection yolu yalnız canonical mutlak Windows yolu ve ağ-paylaşımı biçimlerinin reddi bakımından sözlüksel olarak doğrulanır; gerçek volume kimliği bu aşamada kanıtlanmış değildir. Append-only mutation envelope global sequence, actor, device, schema, hash, durable idempotency fingerprint'i, provider evidence ve projection hash bağlarını taşır. Persist katmanı quorum commit kaydı ile yerel projection uygulamasını tek atomik işlem olarak sunmak zorundadır. Provider commit sonrası yerel uygulama başarısız olursa karar consensus commit'i inkâr etmez; yerel uygulamayı başarısız bildirip safe mode'a girer.

Migration 113 checksum'u `3f7b7e02e462744f704ced2255b75d712b90930c807889f13f8dd1d4d2f6e596` değeridir. Üç STRICT tablo, immutable mutation/snapshot kayıtları, active leader/fence/policy/epoch eşliği, tenant-scope idempotency, local applied index ile exact commit bağı, monotonik sequence/entity version/commit index/zaman ve geri alınamaz certificate revocation ile fail-closed kalır. Bilinmeyen kaynak türleri varsayılan olarak `strong` tutarlılığa gider. Otomatik failover yalnız topoloji uygunluğu değil, yapılandırılmış üretim sağlayıcısı, sağlıklı quorum ve gerçek çok-node doğrulaması birlikte varsa kullanılabilir sayılır.

Migration 113 ve sentetik test-double kanıtı gerçek Raft, mTLS sertifikası, çok node, partition, failover veya bootstrap UAT değildir. İnce native Windows Service Host kaynağı ve derlemesi yerelde vardır: Node iş kurallarını tekrar etmez, DPAPI LocalMachine ile korunan exact yapılandırma kullanır, tek kullanımlı kimliği doğrulanmış named-pipe kapatma kanalı ve sınırlı yeniden başlatma uygular. Host çıktısı imzasızdır; gerçek SCM kurulum/başlatma/durdurma/yeniden başlatma ve kullanıcı oturumu kapalı yaşam döngüsü çalıştırılmamıştır. Üretim consensus runtime composition'ı yoktur; mevcut uygulama ağ kullanmaz. `productionConsensusVerified=false`, `windowsServiceHostVerified=false`, `countsAsRequirementPass=false` kalır.
