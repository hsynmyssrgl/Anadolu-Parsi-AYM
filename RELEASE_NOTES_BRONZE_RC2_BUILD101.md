# Bronze RC2 Build 101 Sürüm Notları

Build 101, bağımlılık tedarik zincirini çalışma ortamından bağımsız ve denetlenebilir hale getirir. Lockfile dış paketleri resmî npm registry ve SHA-512 bütünlüğüyle sabitler. Yeni RC2 kapı yöneticisi doğrulamaları onaylı sırada yürütür, ilk başarısızlıkta durur ve çalıştırılmayan her adımı `NOT_RUN` olarak kaydeder.

Bu sürüm yalnızca Bronze RC2 Active Development kaynak teslimidir. Final, Code Freeze, Silver veya Gold terfisi değildir.
