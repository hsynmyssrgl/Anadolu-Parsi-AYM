# Anadolu Parsı Aile Yaşam Merkezi — Bronze Build 180

- Uygulama sürümü: `30.07.2026.180`
- Paket sürümü: `30.7.2026-180`
- Politika: `PPT-LIFECYCLE-STRICT-V1`

## Eklenenler

- Makine tarafından okunur katı ürün yaşam döngüsü politikası.
- Domain katmanında yeni ürün geliştirmesini yalnız Bronze’a izin veren doğrulama API’si.
- Silver ve Gold çalışma türlerini yeni ürün geliştirmesine kapatan sözleşme.
- Ağır API ertelemesi için yedi zorunlu mimari yeterlilik alanı.
- OneDrive, iCloud/Google Drive, harita/canlı konum, sağlık-sigorta-kurum, haricî kimlik, AI sağlayıcısı ve companion eşitleme için Bronze hedefli erteleme kaydı.
- DEC-068 sürüm rengi, DEC-069 varsayılan aile yakınlık kataloğu ve DEC-070 katı yaşam döngüsü kararlarının Ana Karar Kaydı’na eklenmesi.
- Aktif kapsam, teknik, güvenlik, UI, test, doğrulama, açık işler, katkı ve teslim belgelerinin aynı politikaya bağlanması.

## Kural

Bütün ürün geliştirmeleri Bronze’da tamamlanır. Ağır API üretim adaptörü askıya alınsa bile sağlayıcıdan bağımsız altyapı Bronze’da eksiksiz bulunur. Silver test ve altyapı iyileştirme; Gold üretim kanalıdır.
